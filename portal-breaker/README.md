# Portal Breaker (Fabric, Minecraft 26.3)

Hit a reinforced deepslate block (the Ancient City portal frame) with any pickaxe:
the whole connected frame breaks at once and the blocks go to your inventory.
Sneak while hitting to break only one block. Does nothing in creative mode.

Works in singleplayer. On a multiplayer server it works only if the server also has the mod,
because the server decides which blocks can be broken.

Needs Fabric Loader and Fabric API.
